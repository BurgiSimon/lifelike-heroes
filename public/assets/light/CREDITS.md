# Window light hero: external assets

Every file in this folder that the hero did not make itself is listed here, with where it came from and its licence.
Everything else in the scene is the hero's own code.

The light itself (the window's picture on the wall, the lime tree, the curtain, the crystals and their spectra) is procedural,
written for this hero. Its measures are real ones: the sun's width in the sky (0.53°), which sets how soft each shadow is at its
distance; and the refractive index of lead crystal from red to violet (1.588 to 1.630), which sets where each colour lands.
The lettering is the page's own headline, set in Mona Sans (see the project README).
